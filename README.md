# Winn Cook

I run institutional research at Fort Lewis College as a department of one: federal and state reporting, data governance, and the analysis behind the college's salary, budget and retention decisions. Outside work I build data tools in Python and SQL.

## Work you can open

- **IPEDS peer analysis**: college-to-college comparisons from public federal data, built in Python and DuckDB with sources for every figure. [Live](https://winncook.github.io/fort-lewis-ipeds-peer-analysis/) · [Code](https://github.com/WinnCook/fort-lewis-ipeds-peer-analysis)
- **Compensation model**: illustrative pay scenarios from public IPEDS HR data, with the assumptions on screen. Separate from the analysis the college's salary committee uses. [Live](https://winncook.github.io/fort-lewis-compensation-demo/) · [Code](https://github.com/WinnCook/fort-lewis-compensation-demo)

## Things I built and run (private code, happy to walk through it)

- **Grant Nexus**: checks new federal grants every morning and matches them to faculty and department research areas. If a daily check fails, the last good version stays live. Fort Lewis is the free pilot client.
- **AskDurango**: a search tool for La Plata County public records (parcels, sales, permits, business filings).
- **Registrar course-plan check**: a Python tool that compares faculty course plans with past offerings and flags exceptions each term.

## Tools

SQL, Python, DuckDB, Excel / Power Query, Power BI, Tableau, Workday, Banner, Git
